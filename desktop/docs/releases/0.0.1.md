# Rust Loop Connect 0.0.1

Initial open-source desktop release for the EK Loop Connect controller on Linux
and Windows.

- Dashboard for three temperature inputs, six fan RPM/PWM channels, and raw
  flow/level readings.
- Explicit per-channel PWM control and temperature curves, with the F6
  pump-compatible mapping preserved.
- Global RGB effects, local profiles, and a clearly labeled hardware-free demo.
- Exclusive device access and a session lockout after communication errors.
  Connecting does not automatically change PWM or RGB settings.

## Downloads

Choose one of the two raw compiled binaries; no archive extraction is required:

- **Linux x86_64:** `rust-loop-connect-linux-x86_64`
- **Windows x86_64:** `rust-loop-connect-windows-x86_64.exe`

On Linux, make the downloaded file executable and start it:

```sh
chmod +x rust-loop-connect-linux-x86_64
./rust-loop-connect-linux-x86_64
```

On Windows, run the downloaded `.exe`.

## Initial-release limits

Native builds and automated tests do not establish physical controller acceptance.
**Windows testing with a real USB controller, fan/PWM outputs and RGB remains
pending.** Physical fan response and curve calibration must be checked with a
suitable attached test fan; no automatic calibration sweep is performed.

Only global RGB control is provided. Independent LED-port/pixel control and
firmware flashing are not included. Flow and level values remain raw until sensor
presence and calibration are verified. Close competing controller/RGB utilities;
on Linux, use this desktop application separately from the custom hwmon driver
and `fancontrol`.

Thanks to [Pavel Herrmann's EK Loop Connect driver and protocol documentation](https://github.com/pavelherr/ek-loop-connect)
for the fan/sensor protocol foundation, and to [OpenRGB](https://gitlab.com/CalcProgrammer1/OpenRGB)
for public RGB protocol work. Rust Loop Connect is released under GPL-2.0-or-later.
